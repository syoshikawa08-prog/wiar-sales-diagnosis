# 株式会社WIAR | 売上アップ無料診断 WEBアプリ

「客単価 × 見込客 × 成約率」を自己評価し、経営者が**今いちばん優先したい改善分野**を提示する無料診断です。
スマホ・PC両対応で、**ホーム画面への追加とオフライン診断**に対応したPWA（Progressive Web App）です。

## 診断フロー

1. `index.html` をブラウザーで開きます（公開時はHTTPS URLを使用）。
2. 客単価・見込客・成約率の現状の自己満足度を、それぞれ1〜10点で選択します。
3. 現在の掛け算スコアと「1項目だけ＋1点」したときのスコア3パターンを比較します。
4. 最大スコアの項目を優先テーマとして表示します。同率の場合は併記します。
5. 客単価ならブランド戦略、見込客ならマーケティング戦略、成約率ならセールス戦略の改善案を示します。
6. 「株式会社WIARに無料相談する」を押すと、宛先 `info@wiar-co-ltd.com`、件名、自己評価と診断結果が入力されたメールの下書きが開きます。メールアプリが未設定なら開けない場合があります。

**入力例**：5×5×10=250 → 客単価＋1=300、見込客＋1=300、成約率＋1=275 → 客単価・見込客が同率1位。

※ 点数の掛け算は経営上の優先順位を考えるための簡易指標であり、金額や売上増加率の予測ではありません。10点を選んだ項目も比較上は仮に11点として計算します。

## ファイル構成

- `index.html`: 画面、診断ロジック、結果、メール問い合わせ
- `manifest.webmanifest`: スマホへのインストール設定
- `sw.js`: オフライン動作のためのキャッシュ
- `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`: WIAR仮デザインのアプリアイコン
- `preview.png`, `desktop-preview.png`: 画面参考画像（公開に必須ではありません）

## 公開するには

1. 本フォルダー内の `index.html`、`manifest.webmanifest`、`sw.js`、`favicon.svg`、各PNGアイコンを**同じ階層**にアップロードしてください。
2. HTTPSのURLで配信してください。例：会社の既存サイトの `https://（会社のドメイン）/shindan/` など。
3. スマホとPCで開いて診断を動かし、問い合わせボタンでメールの下書きが作成されることを確認してください。
4. 公開URLを使って名刺掲載用のQRコードを作成してください。**本パッケージだけでは公開URLは発行されません。**

### スマホでアプリとして使う

- iPhone（Safari）: 共有 →「ホーム画面に追加」
- Android（Chrome）: メニュー →「アプリをインストール」または「ホーム画面に追加」
- オフライン診断はHTTPSで一度オンライン訪問・キャッシュされた後に利用できます。メール送信には通常インターネット接続が必要です。

## 編集箇所

- 宛先の変更: `index.html` 内 `const destination = 'info@wiar-co-ltd.com';`
- 戦略の文章: `const defs = [...]` の `advice` を変更
- 色・文字: `index.html` のCSSおよび画面内のテキスト
- 会社の正式ロゴに変更する場合はアイコン画像やヘッダーを差し替え可能

## プライバシーと運用上の注意

- 入力スコアはブラウザ内で処理され、サーバーへ自動送信・保存されません。
- メールは自動送信されず、利用者本人の送信操作が必要です。
- 管理者に診断者リストを蓄積する仕組み（フォーム・DB・CRM）はありません。問い合わせリードを確実に収集したい場合は別途フォーム方式を実装します。
- 静的ファイルのみで動作するため、サーバー実装・APIキーは不要です。
